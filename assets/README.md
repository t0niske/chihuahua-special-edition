# Картинки для сайта

Положите PNG с прозрачным фоном в эту папку с такими именами. Сайт подхватит их сам: заглушки исчезнут.

## Уже есть
- `cover-dog.webp` — собака с обложки (вырезана из макета)
- `paw.webp` — лапа для «Характера» (вырезана из макета)

## История («Древние корни»)
- `map.webp` — карта Мексики со штатом Чиуауа (правая колонка, во всю высоту)
- `techichi.png` — глиняная фигурка собаки
- `flag.png` — флаг Мексики
- `sombrero.png` — сомбреро над буквой «Й»
- `maracas.png` — маракасы
- `cactus.png`, `cactus-2.png` — кактусы внизу слева
