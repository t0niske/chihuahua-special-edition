# Chihuahua — Special Edition

Одностраничный сайт о чихуахуа в стиле модного журнала: обложка, история породы, характер, интересные факты, листалка образов «Look of the day» и советы владельцам.

Открыть сайт: https://t0niske.github.io/chihuahua-special-edition/

## Устройство

- `index.html` — разметка страницы
- `styles.css` — стили; десктопная сетка повторяет макеты (1 единица = 1px макета шириной 2000)
- `script.js` — вытянутые заголовки, листалка образов, появление блоков, заглушки для картинок
- `assets/` — картинки (список имён — в `assets/README.md`) и текстура зерна `grain.png`

Сайт статический: достаточно открыть `index.html` в браузере.
